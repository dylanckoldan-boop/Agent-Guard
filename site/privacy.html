Privacy policy

Nothing about you leaves your machine

Foldward is a local tool and this is a static website. Neither collects anything about you. This page says so plainly.

The application

  • No telemetry. Foldward does not send usage data, crash reports or anything else about you, and it has no analytics. The one time it contacts the network is when you explicitly run Check for updates, which asks GitHub for the latest version number and nothing more; it never does so on its own.
  • No account, no cloud. There is nothing to sign in to. Your agents, detections and settings never leave your computer.
  • On-device storage only. Everything Foldward keeps — your settings, the circle signing key, the agents you register, the revocation registry, the hash-chained audit, and any quarantined files with their encryption key — lives in your own per-user data folder, which other user accounts can't read (programs running as you can). Nothing is uploaded, and there is no cloud copy.
  • Containment stays inside your perimeter. Foldward acts only on resources you own — it never reaches into an agent's own infrastructure.
  • Open source. Foldward is MIT licensed, so you can read exactly what it does and verify these claims for yourself.

This website

  • No JavaScript, no cookies. The site is plain HTML and CSS. It sets no cookies and runs no scripts.
  • No third-party requests. Fonts are your system's own and nothing is loaded from other servers, so no outside party sees your visit.
  • No analytics or tracking. We do not log, profile or measure visitors. The only record of your visit is whatever the host keeps in standard server logs: the site is published with GitHub Pages, which may log visitors' IP addresses — see GitHub's privacy statement.

Contact

Questions, or a security concern? Open an issue or use private vulnerability reporting on the project repository.

This policy is dated 31 October 2026. If its meaning ever changes, this date changes with it.
